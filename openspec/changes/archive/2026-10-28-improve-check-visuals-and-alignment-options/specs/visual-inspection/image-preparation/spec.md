## ADDED Requirements

### Requirement: REQ-042 型番共通の位置合わせ方法を選択する

システムは、運用者が型番設定を読み込む時に、`alignment.method` の省略時は `ORB` を選び、`ORB`、`ECC`、`NONE` のいずれかと選択方法だけの設定を検証しなければならない(MUST)。<br />
`ORB` の条件は `alignment.orb`、`ECC` の条件は `alignment.ecc` に置き、`NONE` には方法固有の条件を置かない。旧形式の `alignment` 直下のORB条件は受け付けない。`ECC` の移動上限は画像幅・高さの各0.1、回転上限は10度、拡大縮小は0.9～1.1倍を対象とする。`alignment.ecc.min_correlation` は運用者が指定する0より大きく1以下の有限数であり、これを下回る推定を成功扱いしない。

#### Scenario: REQ-042-S01 省略時にORBを選ぶ

- **GIVEN** `alignment` に `method` がなく、有効な `orb` 条件がある
- **WHEN** 運用者が型番のコマンドを実行する
- **THEN** `ORB` を選び、現在のORBの成功条件を用いる

#### Scenario: REQ-042-S02 方法別の条件だけを受け付ける

- **GIVEN** `method` が `ORB`、`ECC`、`NONE` のいずれかで、対応する条件だけがある
- **WHEN** 運用者が型番のコマンドを実行する
- **THEN** その方法と条件を使用でき、方法の選択は型番内の全グループに共通となる

#### Scenario: REQ-042-S03 不正な方法と旧形式を拒否する

- **GIVEN** 未知の方法、選択方法に無関係な条件、不正な数値、または旧形式のORB条件が `alignment` 直下にある
- **WHEN** 運用者が型番のコマンドを実行する
- **THEN** 不正な設定項目を示して入力不備として終了し、既存成果物を更新しない
- **AND** 運用者は方法別の新形式へ修正して再実行できる

## MODIFIED Requirements

### Requirement: REQ-001 型番設定と分割範囲の確認

システムは、運用者が型番を指定して分割位置確認を要求した時に、型番設定の基準画像へ、判読できる枠と分割 ID を重ねた全範囲の確認画像、および各グループの対象範囲とグループ ID・分割 ID を区別できる確認画像を保存しなければならない(MUST)。

座標は左上原点、右方向を x、下方向を y とするピクセル単位とし、分割範囲は左上を含み右端・下端を含まない正方形とする。
`setting.ini` の `[IMAGE]` セクションにある `SIZE` は、値と同じ行にコメントを含めず、値全体を正の10進整数として扱う。
`RESIZE` は縦横に適用する0より大きく1以下の倍率とし、未指定時は1とする。<br />
型番設定の `range.x`・`range.y` は縮小前の基準画像の座標とする。<br />
確認画像では指定倍率で座標を換算し、縮小後の基準画像上に切り出し位置を表示する。<br />
換算後の座標は、縮小前座標に `RESIZE` を掛け、小数部が0.5以上なら切り上げる整数とする。<br />
分割範囲の一辺は縮小後も `SIZE` ピクセルとする。
型番設定の基準画像 `base` はディレクトリを含まないファイル名だけを許可し、`data/01_original_train/<型番>/` 配下のファイルとして解決しなければならない(MUST)。POSIX の絶対パス、`.`、`..`、パス区切り文字を含む値、または解決後に既知ルート外となる値を処理開始前に拒否しなければならない(MUST)。

#### Scenario: REQ-001-S01 有効な設定から確認画像を生成する

- **GIVEN** 型番の基準画像、正の整数である画像サイズ、有効な縮小倍率、一意な分割 ID、および縮小前の基準画像で指定し、換算後に縮小後の画像内に収まる左上座標が設定されている
- **WHEN** 運用者が `check --model <型番>` を実行する
- **THEN** システムは縮小前座標を換算した縮小後の基準画像上に各分割範囲の矩形と ID を描いた型番別の全範囲確認画像とグループ別確認画像を保存する
- **AND** 処理結果、出力先および処理時間を運用者へ表示する

#### Scenario: REQ-001-S02 無効な分割範囲を拒否する

- **GIVEN** 換算後の分割範囲が縮小後の基準画像外にはみ出す、分割 ID が重複する、画像サイズが整数でないか正でない、縮小倍率が0以下・1超・非数値の設定がある、または有効な倍率でも基準画像の縮小後の縦横いずれかが0ピクセルとなる
- **WHEN** 運用者が `check --model <型番>` を実行する
- **THEN** システムは対象の設定項目または画像と理由を示して処理をエラー終了する。縮小不能な画像は処理失敗、設定と範囲の不備は入力不備として扱う
- **AND** 不完全な確認画像を正常結果として保存しない

#### Scenario: REQ-001-S03 基準画像のルート外参照を拒否する

- **GIVEN** 型番設定の `base` に POSIX の絶対パス、`.`、`..`、パス区切り文字を含む値、または学習元画像の型番別ルート外へ解決される値が指定されている
- **WHEN** 運用者が当該型番のコマンドを実行する
- **THEN** システムは `base` が安全なファイル名ではないことを示して処理開始前にエラー終了する
- **AND** 既知ルート外のファイルを読み書きしない

#### Scenario: REQ-001-S04 縮小前の指定位置を確認する

- **GIVEN** `RESIZE = 0.5`、`SIZE = 500`、縮小前基準画像で `x = 400` と `x = 401` の異なる分割 ID がある
- **WHEN** 運用者が `check --model <型番>` を実行する
- **THEN** システムは縮小後画像の `x = 200` と `x = 201` からそれぞれ500ピクセル四方の範囲を描き、指定した分割 ID を表示する

#### Scenario: REQ-001-S05 重複所属を確認する

- **GIVEN** 同じ分割IDを含む二つのグループがある
- **WHEN** 運用者が `check --model <型番>` を実行する
- **THEN** 全範囲画像と両グループの確認画像に同じ分割位置とIDが表示される
- **AND** 各グループの対象範囲を区別できる

#### Scenario: REQ-001-S06 複数範囲の色と番号を区別する

- **GIVEN** 複数の分割IDがあり、同じIDを複数のグループが使用する
- **WHEN** 運用者が `check --model <型番>` を実行する
- **THEN** 全範囲画像とグループ別画像で、枠線と番号が画像の大きさに応じて判読でき、異なるIDは区別できる色で表示される
- **AND** 同じ分割IDはすべての確認画像で同じ色を使用し、元画像と分割範囲の座標は変更されない

### Requirement: REQ-002 学習画像の位置合わせ・分割・除外

システムは、運用者が学習準備を要求した時に、型番で選択した方法に従って各学習元画像を基準画像へ位置合わせするか位置合わせを省略し、ブラックリスト対象を除外して、指定グループまたは全グループについて、元画像名と2桁ゼロ埋めの分割 ID で対応付く分割画像とグループ別の準備記録を保存しなければならない(MUST)。

`ORB` 位置合わせは、ホモグラフィ推定前の対応点数が設定された最低マッチ数以上であり、設定されたRANSAC再投影誤差とRANSAC信頼確率でホモグラフィを推定でき、返却マスクから算出したインライア比率が設定された最低値以上である場合だけ成功としなければならない(MUST)。<br />
対応点は各特徴点の近傍2候補の距離を比較し、最良候補の距離が次点候補の距離に比率閾値を掛けた値より小さい場合だけ採用する。<br />
`knn_k` は2、`ratio_threshold` は0より大きく1より小さい値とする。<br />
`ORB` の初期値は `knn_k` 2、`ratio_threshold` 0.75、最低マッチ数10、RANSAC再投影誤差8.0px、RANSAC信頼確率0.95、最低インライア比率0.2としなければならない(MUST)。<br />
対象グループの成果物は完成まで旧成果物を変更せず、完成したグループから置き換える。公開前の失敗・中断では旧成果物を維持し、次回実行時に残った一時領域を削除する。公開途中の中断による欠落は学習の利用前に拒否し、準備のやり直しを案内する。

#### Scenario: REQ-002-S01 学習用分割画像を生成する

- **GIVEN** 有効な型番設定と、縮小後に設定した対応点条件で位置合わせ可能な学習元画像がある
- **WHEN** 運用者が `train-pre --model <型番>` を実行する
- **THEN** システムは基準画像と元画像を指定倍率で縮小して位置合わせし、縮小前座標を換算した開始位置から `SIZE` ピクセル四方の全グループで使う分割範囲を切り出し、`<元画像名>_<2桁分割ID>.<元拡張子>` の名称で対応するグループの学習領域へ保存する
- **AND** 元画像は変更しない

#### Scenario: REQ-002-S02 ブラックリスト対象を除外する

- **GIVEN** 学習元画像名と分割 ID の組み合わせが型番のブラックリストに指定されている
- **WHEN** 運用者が学習準備を実行する
- **THEN** システムは該当する分割画像を学習領域へ保存しない
- **AND** 除外した元画像名と分割 ID を処理結果へ記録する

#### Scenario: REQ-002-S03 位置合わせに失敗した学習画像を除外する

- **GIVEN** `ORB` または `ECC` の位置合わせが成功条件を満たさず、基準画像へ位置合わせできない
- **WHEN** 運用者が学習準備を実行する
- **THEN** システムは該当する元画像の全分割を学習対象から除外する
- **AND** 元画像名、失敗理由および再確認が必要であることを警告として表示する

#### Scenario: REQ-002-S04 分割範囲外をエラーにする

- **GIVEN** 位置合わせ後または位置合わせ省略時の学習画像に対して分割範囲が画像外にはみ出す
- **WHEN** 運用者が学習準備を実行する
- **THEN** システムは元画像名と分割 ID を示して処理をエラー終了する
- **AND** 公開前なら既存の対象グループ成果物を変更しない

#### Scenario: REQ-002-S05 読込み不能な学習画像で既存成果物を維持する

- **GIVEN** 型番の学習元画像を画像として読み込めない
- **WHEN** 運用者が学習準備を実行する
- **THEN** システムは対象の元画像名を示して処理失敗としてエラー終了する
- **AND** 公開前なら既存の対象グループ準備成果物を維持する

#### Scenario: REQ-002-S06 対応点判定設定の不備を拒否する

- **GIVEN** `knn_k` が2でない、または `ratio_threshold` が0以下・1以上・非数値である
- **WHEN** 運用者が学習準備を実行する
- **THEN** システムは不正な設定項目を示して処理開始前にエラー終了する
- **AND** 元画像と既存の準備成果物を維持する

#### Scenario: REQ-002-S07 指定グループだけを準備する

- **GIVEN** 複数グループと既存の別グループの準備結果がある
- **WHEN** 運用者が `train-pre --model <型番> --group <ID>` を実行する
- **THEN** 指定グループの分割だけを準備してそのグループの記録を更新する

#### Scenario: REQ-002-S08 全グループを一度の実行で準備する

- **GIVEN** 複数グループで同じ分割を参照する有効な設定がある
- **WHEN** 運用者が `train-pre --model <型番>` を実行する
- **THEN** 各グループの対象分割と準備記録が完成したグループから順に公開される
- **AND** 同じ元画像に対するグループ間の位置合わせ結果が一致する

#### Scenario: REQ-002-S09 残った一時領域を整理する

- **GIVEN** 前回の中断で学習準備の一時領域が残り、正式領域には旧成果物がある
- **WHEN** 運用者が次の学習準備を実行する
- **THEN** 残った一時領域を削除して新たに準備し、公開まで旧成果物を変更しない

#### Scenario: REQ-002-S10 公開途中の欠落を拒否する

- **GIVEN** 学習準備成果物の削除と公開の間で中断し、対象グループの成果物が欠けている
- **WHEN** 運用者がそのグループの学習を実行する
- **THEN** 準備成果物の欠落を示して拒否し、`train-pre` のやり直しを促す

#### Scenario: REQ-002-S11 位置合わせを省略した学習画像を準備する

- **GIVEN** `alignment.method` が `NONE` で、学習元画像の指定分割範囲が画像内に収まる
- **WHEN** 運用者が `train-pre --model <型番>` を実行する

#### Scenario: REQ-002-S12 ECCの変形範囲と失敗を扱う

- **GIVEN** `alignment.method` が `ECC` で、学習元画像に移動・回転・拡大縮小、または推定不良がある

#### Scenario: REQ-025-S03 有効な輝度補正条件の変更を区別する

- **GIVEN** 輝度補正が有効な準備成果物がある
- **WHEN** 運用者が輝度補正条件を変更して成果物を照合する
- **THEN** 条件の異なる準備指紋として扱われ、旧成果物は使用されない

#### Scenario: REQ-025-S04 検査値だけを変更して再検査する

- **GIVEN** 新形式の準備・学習成果物がある
- **WHEN** 運用者が分割の検査閾値または表示範囲だけを変更して `test` を再実行する
- **THEN** 準備指紋は変わらず、再準備・再学習なしで結果を更新できる

#### Scenario: REQ-025-S05 位置合わせ方法と条件の変更を区別する

- **GIVEN** 旧方法または旧条件の学習・試験準備成果物がある
- **WHEN** 運用者が `alignment.method` または選択方法の条件を変更して学習・検査を実行する
- **THEN** 準備指紋の不一致で旧成果物を拒否し、再準備を案内する
