## MODIFIED Requirements

### Requirement: NREQ-001 対象環境と実行記録

システムは、Ubuntu 24.04 LTS (ネイティブまたは WSL2) および Apple silicon の macOS で Python 3.13 を使用する場合、学習、推論、結果保存を実行でき、各コマンドの結果、処理時間、警告・エラー、主要依存関係およびデバイス情報を記録できなければならない(MUST)。<br />
利用可能な CUDA GPU がない場合は CPU を使用する。macOS での Apple GPU 利用はこの要件に含めない。

#### Scenario: NREQ-001-S01 対象 OS の実行契約を確認する

- **GIVEN** Ubuntu 24.04 LTS (ネイティブまたは WSL2) または Apple silicon の macOS に固定済み依存関係と有効な小規模試験データが導入されている
- **WHEN** 運用者が分割位置確認から検査までのスモーク試験を実行する
- **THEN** システムは全コマンドの終了状態、処理時間、依存関係の版および使用デバイスを運用記録へ出力する
- **AND** 新しく生成したモデル、画像および JSON を対象環境上で読み戻せる

#### Scenario: NREQ-001-S02 GPU 不能時の復旧可能性を確認する

- **GIVEN** GPU 経路を無効化した対象環境の試験環境がある
- **WHEN** 運用者が学習と検査のスモーク試験を実行する
- **THEN** システムは CPU へ切り替えて完了し、切り替え理由と処理時間を運用記録へ出力する
