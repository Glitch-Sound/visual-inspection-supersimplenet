## 背景と現行業務フロー

1. 運用者は Ubuntu 24.04 LTS または Windows 11 を対象環境として依存関係を導入し、型番設定と画像を用意する。
2. 運用者は `check`、`train-pre`、`train`、`test-pre`、`test` を実行し、準備成果物、学習成果物、検査結果を読み戻す。
3. 評価者は結果を確認する。対象 OS での一連の実行と読戻しは受け入れ確認として残っている。

## 利用者と運用者

| 役割 | 利用場面 | 目的・必要な判断 |
| --- | --- | --- |
| 運用者 | 環境導入、画像準備、学習、検査、再実行 | 対象環境で全工程と成果物読戻しが成立するか判断する |
| 評価者 | 検査結果の確認 | 検査結果と未検証条件を区別して評価する |

## 解決する課題

現在の対象環境と受け入れ案内は Windows 11 を含み、利用を予定する Ubuntu 24.04 LTS (ネイティブまたは WSL2) と Apple silicon の macOS に一致しない。<br />
依存関係の取得条件、入力検証、試験、延期中の受け入れ確認にも Windows 向けの記述や分岐が残り、対象環境の判断と検証範囲を曖昧にする。

## 変更後の業務フロー

1. 運用者は Ubuntu 24.04 LTS (ネイティブまたは WSL2) または Apple silicon の macOS に固定済み依存関係を導入する。
2. 運用者は型番設定と元画像を確認し、不正な絶対パスや親ディレクトリ参照を修正する。
3. 運用者は既存成果物を引き継がず、`check`、`train-pre`、`train`、`test-pre`、`test` を順に実行する。失敗した場合は原因を直して必要な工程から再実行する。
4. 運用者は対象環境ごとの自動試験と実画像による全工程、成果物読戻しを記録する。評価者は未検証条件を確認して運用開始の可否を判断する。

## 対象範囲

### 対象

- Ubuntu 24.04 LTS (ネイティブまたは WSL2) と Apple silicon の macOS を対象環境とする。
- Windows 固有の入力検証、試験分岐、依存関係取得条件を取り除く。POSIX 絶対パス、区切り文字、親ディレクトリ参照の拒否は維持する。
- 現行の README、正式仕様、進行中 change の対象環境と試験方針を整合させ、延期中の受け入れ確認を新しい対象環境へ引き継ぐ。
- 準備・学習・検査の全再実行と、対象環境での試験・読戻しを扱う。

### 対象外

- 旧準備成果物、旧学習成果物、旧検査結果との互換性と移行。全工程の再実行を前提とするため。
- Windows 11 の動作保証と受け入れ確認。対象環境から外すため。
- アーカイブ済み change と過去の証跡の書換え。過去の判断と実施記録を保持するため。
- 本番利用の検出性能、誤検出率、処理時間の数値基準。この変更の対象環境整理では決定しないため。

## 運用開始の受け入れ条件

- AC-001: Ubuntu 24.04 LTS (ネイティブまたは WSL2) と Apple silicon の macOS で固定済み依存関係を導入でき、既存の自動試験が成功する。
- AC-002: 対象環境で全工程を再実行し、新しく生成した準備成果物、学習成果物、検査結果を読み戻せる。実行環境と使用デバイスを記録する。
- AC-003: 基準画像名と成果物名の POSIX 絶対パス、区切り文字、親ディレクトリ参照は拒否され、通常のファイル名は受け入れられる。
- AC-004: 現行の導入案内、正式仕様、延期中の受け入れ確認が新しい対象環境と再実行方針を示し、Windows 11 を現行対象として案内しない。

なし。

### 変更する既存能力

- `visual-inspection/model-evaluation`: 対象環境、全工程の実行記録と検査結果の受け入れ方針を更新する。

## 影響範囲

- **利用者・業務**: **BREAKING**。Windows 11 は対象環境から外れる。運用者は Ubuntu または macOS で全工程を再実行する。
- **API・外部連携**: CLI 名と結果形式は変更しない。Windows 向け配布・動作保証は終了する。
- **データ**: **BREAKING**。旧準備成果物、旧学習成果物、旧検査結果は引き継がない。移行処理は用意しない。
- **品質・運用**: 対象環境ごとの自動試験と実機・実画像の確認を区別し、未実施分は未検証として追跡する。macOS の GPU 利用は保証せず、利用可能なデバイスを記録する。
