## ADDED Requirements

### Requirement: REQ-039 成功画像の残り誤差を確認する

システムは、学習または試験の画像準備で元画像の位置合わせが成功した時に、各元画像のインライア再投影誤差を準備manifestへ記録しなければならない(MUST)。<br />
記録値は、選択した変換で移したインライア対応点と基準画像の対応点とのユークリッド距離の二乗平均平方根とし、`alignment.inlier_reprojection_rmse_px` に有限の0以上の値として、縮小後画像のピクセル単位で記録する。<br />
学習manifestはグループ別、試験manifestは型番別に元画像の値を列挙するため、運用者は成功画像の値を抽出して両集合の分布を確認できる。<br />
位置合わせ失敗画像に誤差値を実測値として記録してはならない(MUST NOT)。

#### Scenario: REQ-039-S01 学習画像の誤差分布を確認する

- **GIVEN** 異なる残り誤差を持つ複数の学習元画像が位置合わせに成功する
- **WHEN** 運用者が学習準備を実行する
- **THEN** グループ別manifestの各成功元画像に縮小後ピクセル単位の再投影誤差が記録され、運用者は値の分布を確認できる
- **AND** 同じ元画像を共有するグループ間では同じ誤差を記録する

#### Scenario: REQ-039-S02 試験画像の誤差分布を確認する

- **GIVEN** 複数の試験元画像が位置合わせに成功する
- **WHEN** 運用者が試験準備を実行する
- **THEN** 型番別manifestの各成功元画像に同じ定義の再投影誤差が記録され、運用者は学習・試験の分布を比較できる

#### Scenario: REQ-039-S03 失敗画像の誤差を実測値と区別する

- **GIVEN** 学習または試験元画像の位置合わせが失敗する
- **WHEN** 運用者が画像準備を実行する
- **THEN** 該当元画像の状態と失敗理由が記録され、再投影誤差は実測値として記録されない
- **AND** 学習画像は除外、試験画像は未判定として扱われる

## MODIFIED Requirements

### Requirement: REQ-002 学習画像の位置合わせ・分割・除外

システムは、運用者が学習準備を要求した時に、型番の各学習元画像を基準画像へ位置合わせし、ブラックリスト対象を除外して、指定グループまたは全グループについて、元画像名と2桁ゼロ埋めの分割 ID で対応付く分割画像とグループ別の準備記録を保存しなければならない(MUST)。

ORB位置合わせは、変換推定前の対応点数が設定された最低マッチ数以上であり、選択した変換モデルを設定されたRANSAC再投影誤差とRANSAC信頼確率で推定でき、返却マスクから算出したインライア比率が設定された最低値以上である場合だけ成功としなければならない(MUST)。
対応点は各特徴点の近傍2候補の距離を比較し、最良候補の距離が次点候補の距離に比率閾値を掛けた値より小さい場合だけ採用する。<br />
`knn_k` は2、`ratio_threshold` は0より大きく1より小さい値とする。<br />
初期値は `knn_k` 2、`ratio_threshold` 0.75、最低マッチ数10、RANSAC再投影誤差8.0px、RANSAC信頼確率0.95、最低インライア比率0.2としなければならない(MUST)。<br />
型番共通の `alignment.transform_model` は `homography` (射影変換) または `similarity` (平行移動・回転・等方拡大縮小だけを許す変換) とし、省略時は `homography` とする。<br />
`alignment.border_mode` は `black` (画面外を黒で埋める) または `replicate` (端画素を複製する) とし、省略時は `black` とする。<br />
変換モデルと埋め方は学習・試験に同じ設定を適用する。

#### Scenario: REQ-002-S01 学習用分割画像を生成する

- **GIVEN** 有効な型番設定と、縮小後に設定した対応点条件で位置合わせ可能な学習元画像がある
- **WHEN** 運用者が `train-pre --model <型番>` を実行する
- **THEN** システムは基準画像と元画像を指定倍率で縮小して位置合わせし、縮小前座標を換算した開始位置から `SIZE` ピクセル四方の全グループで使う分割範囲を切り出し、`<元画像名>_<2桁分割ID>.<元拡張子>` の名称で対応するグループの学習領域へ保存する
- **AND** 元画像は変更しない

#### Scenario: REQ-002-S02 ブラックリスト対象を除外する

- **GIVEN** 学習元画像名と分割 ID の組み合わせが型番のブラックリストに指定されている
- **WHEN** 運用者が学習準備を実行する
- **THEN** システムは該当する分割画像を学習領域へ保存しない
- **AND** 除外した元画像名と分割 ID を処理結果へ記録する

#### Scenario: REQ-002-S03 位置合わせに失敗した学習画像を除外する

- **GIVEN** 学習元画像が最低マッチ数、選択した変換モデルの推定、または最低インライア比率のいずれかを満たさず、基準画像へ位置合わせできない
- **WHEN** 運用者が学習準備を実行する
- **THEN** システムは該当する元画像の全分割を学習対象から除外する
- **AND** 元画像名、失敗理由および再確認が必要であることを警告として表示する

#### Scenario: REQ-002-S04 分割範囲外をエラーにする

- **GIVEN** 位置合わせ後の学習画像に対して分割範囲が画像外にはみ出す
- **WHEN** 運用者が学習準備を実行する
- **THEN** システムは元画像名と分割 ID を示して処理をエラー終了する
- **AND** 当該実行で生成途中の分割画像を学習可能な一式として扱わない

#### Scenario: REQ-002-S05 読込み不能な学習画像で既存成果物を維持する

- **GIVEN** 型番の学習元画像を画像として読み込めない
- **WHEN** 運用者が学習準備を実行する
- **THEN** システムは対象の元画像名を示して処理失敗としてエラー終了する
- **AND** 生成途中の一式を破棄し、既存の学習準備成果物を維持する

#### Scenario: REQ-002-S06 対応点判定設定の不備を拒否する

- **GIVEN** `knn_k` が2でない、または `ratio_threshold` が0以下・1以上・非数値である
- **WHEN** 運用者が学習準備を実行する
- **THEN** システムは不正な設定項目を示して処理開始前にエラー終了する
- **AND** 元画像と既存の準備成果物を維持する

#### Scenario: REQ-002-S07 指定グループだけを準備する

- **GIVEN** 複数グループと既存の別グループの準備結果がある
- **WHEN** 運用者が `train-pre --model <型番> --group <ID>` を実行する
- **THEN** 指定グループの分割だけを準備してそのグループの記録を更新する
- **AND** 別グループの準備結果を保持する

#### Scenario: REQ-002-S08 全グループを一度の実行で準備する

- **GIVEN** 複数グループで同じ分割を参照する有効な設定がある
- **WHEN** 運用者が `train-pre --model <型番>` を実行する
- **THEN** 各グループの対象分割と準備記録が保存される
- **AND** 同じ元画像に対するグループ間の位置合わせ結果が一致する

#### Scenario: REQ-002-S09 既存設定の分割画像を維持する

- **GIVEN** `transform_model` と `border_mode` を省略した有効な型番設定と、位置合わせ可能な学習元画像がある
- **WHEN** 運用者が学習準備を実行する
- **THEN** 射影変換と黒埋めによる従来と同じ分割画像を保存する

#### Scenario: REQ-002-S10 端画素で画面外を埋める

- **GIVEN** `border_mode` が `replicate` で、位置合わせ後の画面外を含む範囲に非黒色の端画素を持つ学習元画像がある
- **WHEN** 運用者が学習準備を実行する
- **THEN** 対象の分割画像では画面外が端画素で埋まり、黒埋め由来の帯を保存しない

#### Scenario: REQ-002-S11 制限付き変換で位置合わせする

- **GIVEN** `transform_model` が `similarity` で、平行移動・回転・等方拡大縮小で対応する特徴を持つ学習元画像がある
- **WHEN** 運用者が学習準備を実行する
- **THEN** 選択した変換モデルで位置合わせした分割画像を保存し、射影変形またはせん断を加えない

#### Scenario: REQ-002-S12 不正な選択値を拒否する

- **GIVEN** `transform_model` または `border_mode` が許可されない値で、既存の準備成果物がある
- **WHEN** 運用者が学習準備を実行する
- **THEN** 不正な設定項目を示して入力不備として終了し、既存成果物を維持する

#### Scenario: REQ-002-S13 選択した変換を推定できない画像を除外する

- **GIVEN** 対応点数は足りるが、選択した変換を推定できない、インライアがない、または変換結果を有効な画像として扱えない学習元画像がある
- **WHEN** 運用者が学習準備を実行する
- **THEN** 該当元画像の全分割を学習対象から除外し、元画像名と失敗理由を警告する

### Requirement: REQ-003 試験画像の位置合わせと分割

システムは、運用者が試験準備を要求した時に、ブラックリストを適用せず、型番の各試験元画像を基準画像へ位置合わせして、元画像名と2桁ゼロ埋めの分割 ID で対応付く分割画像または未判定引き継ぎ情報を生成しなければならない(MUST)。

試験画像にも学習画像と同じ変換モデル、境界埋め、ORB位置合わせ成功条件を適用しなければならない(MUST)。

#### Scenario: REQ-003-S01 試験用分割画像を生成する

- **GIVEN** 有効な型番設定と、縮小後に設定した対応点条件で位置合わせ可能な試験元画像がある
- **WHEN** 運用者が `test-pre --model <型番>` を実行する
- **THEN** システムは基準画像と元画像を指定倍率で縮小して位置合わせし、縮小前座標を換算した開始位置から `SIZE` ピクセル四方の全分割範囲を切り出し、`<元画像名>_<2桁分割ID>.<元拡張子>` の名称で型番別試験領域へ保存する
- **AND** 学習用ブラックリストに一致する画像であっても試験対象から除外しない

#### Scenario: REQ-003-S02 位置合わせ失敗を検査へ引き継ぐ

- **GIVEN** 試験元画像が最低マッチ数、選択した変換モデルの推定、または最低インライア比率のいずれかを満たさず、基準画像へ位置合わせできない
- **WHEN** 運用者が試験準備を実行する
- **THEN** システムは該当元画像を正常な分割画像一式として保存しない
- **AND** 元画像名、位置合わせ失敗理由、検査時に未判定として記録すべき状態および原則として再撮影が必要であることを`recapture_required=true`として保存して警告する

#### Scenario: REQ-003-S03 試験分割範囲外をエラーにする

- **GIVEN** 位置合わせ後の試験画像に対して分割範囲が画像外にはみ出す
- **WHEN** 運用者が試験準備を実行する
- **THEN** システムは元画像名と分割 ID を示して処理をエラー終了する
- **AND** 当該元画像を正常な検査入力として扱わない

#### Scenario: REQ-003-S04 読込み不能な試験画像で既存成果物を維持する

- **GIVEN** 型番の試験元画像を画像として読み込めない
- **WHEN** 運用者が試験準備を実行する
- **THEN** システムは対象の元画像名を示して処理失敗としてエラー終了する
- **AND** 生成途中の一式を破棄し、既存の試験準備成果物を維持する

#### Scenario: REQ-003-S05 選択した変換と端画素複製を試験へ適用する

- **GIVEN** `similarity` と `replicate` を設定し、画面外を含む範囲に非黒色の端画素を持つ試験元画像がある
- **WHEN** 運用者が試験準備を実行する
- **THEN** 制限付き変換で位置合わせした分割画像を保存し、画面外に黒埋め由来の帯を作らない

#### Scenario: REQ-003-S06 選択した変換の推定失敗を未判定にする

- **GIVEN** 選択した変換を推定できない、インライアがない、または変換結果を有効な画像として扱えない試験元画像がある
- **WHEN** 運用者が試験準備を実行する
- **THEN** 該当元画像に分割画像を保存せず、失敗理由と `recapture_required=true` を記録して検査へ未判定として引き継ぐ

### Requirement: REQ-025 準備結果と設定の対応記録

システムは、運用者が学習または試験の画像準備を実行した時に、分割結果へ影響する設定から作った準備指紋をmanifestへ記録しなければならない(MUST)。
学習準備の指紋には型番共通の分割・位置合わせ条件 (変換モデルと境界埋めを含む)、ブラックリストと対象グループの分割IDを含め、試験準備の指紋にはブラックリストと学習・検査条件を含めない。

#### Scenario: REQ-025-S01 学習準備の条件を記録する

- **GIVEN** 共通分割範囲、位置合わせ条件、ブラックリストと対象グループが設定されている
- **WHEN** 運用者が `train-pre --model <型番> --group <ID>` を実行する
- **THEN** 対象グループの学習manifestに、その分割画像を準備した条件の指紋が記録される

#### Scenario: REQ-025-S02 試験準備の条件を記録する

- **GIVEN** 共通分割範囲と位置合わせ条件が設定されている
- **WHEN** 運用者が `test-pre --model <型番>` を実行する
- **THEN** 全分割の試験manifestに、その分割画像を準備した条件の指紋が記録される
- **AND** ブラックリストやグループの学習・検査条件だけを変更しても指紋は変わらない

#### Scenario: REQ-025-S03 位置合わせ設定変更後の旧準備結果を拒否する

- **GIVEN** 学習または試験準備の後に `transform_model` または `border_mode` を変更した
- **WHEN** 運用者が旧準備結果から学習または検査を開始する
- **THEN** システムは準備指紋の不一致を示して処理を拒否し、再準備を案内する
- **AND** 運用者は対象型番の `train-pre`、`train`、`test-pre`、`test` を順に再実行できる

## 試験方針

| 要件区分 | 試験層 | 試験パターン | 自動化方針・利用者が確認する結果 |
| --- | --- | --- | --- |
| 位置合わせ設定と分割 (REQ-002、REQ-003) | unit / integration | 既定画像の画素一致、両変換モデル、黒埋め・端画素複製、設定不備、推定失敗、インライアなし、学習除外・試験未判定 | 実装変更を伴う各Scenarioを固定画像と制御した対応点で自動検証し、分割画像の画素、警告、成果物の保持を照合する |
| 準備指紋と残り誤差 (REQ-025、REQ-039) | unit / integration | 条件変更による指紋不一致、学習・試験の元画像別誤差、共有グループ、失敗画像の値欠落、非有限値 | 実装変更を伴う各Scenarioを自動検証し、manifestの値・単位・再読込と学習・検査開始時の拒否を照合する |
| 実画像の受け入れ | 対象OSの実機 | 黒帯の有無、画質、誤差分布、検査結果の変化 | 自動試験と区別して対象OS・画像・設定・判定を証跡に残す |
