## ADDED Requirements

### Requirement: REQ-038 分割結果の適用閾値と由来

システムは、分割画像を検査した時に、各分割結果へ実際に適用した閾値とその由来を記録しなければならない(MUST)。<br />
由来は分割ID別の算出値、グループ代替、手動上書きのいずれかとする。<br />
グループ単位では従来のグループ暫定閾値またはグループ検査用閾値を記録し、由来も区別する。<br />
推論に失敗した分割も、選択済みの閾値と由来を記録し、判定は `error` のままとする。

#### Scenario: REQ-038-S01 分割ごとの値と由来を読み戻す

- **GIVEN** 算出値、グループ代替、手動上書きの分割を含むグループがある
- **WHEN** 運用者が検査を実行し、評価者が結果JSONを読む
- **THEN** 各分割の使用閾値と該当する由来を読み戻せる
- **AND** 元画像に一つでも異常分割があれば元画像は異常と記録される

#### Scenario: REQ-038-S02 分割の推論に失敗する

- **GIVEN** 分割の閾値を選択できるが、その分割の推論が失敗する
- **WHEN** 運用者が検査を実行する
- **THEN** 分割は `error` と理由を記録し、選択済みの閾値と由来も読み戻せる
- **AND** 元画像は既存の未判定規則に従う

## MODIFIED Requirements

### Requirement: REQ-018 検査用閾値の選択と記録

システムは、運用者が型番のグループを検査した時に、閾値単位がグループなら従来のグループ暫定閾値またはグループ検査用閾値を全分割に使用し、分割ID単位なら各分割IDの暫定閾値またはその分割IDの検査用閾値を使用して、使用値を結果に記録しなければならない(MUST)。<br />
分割ID単位では分割ID別の手動上書きを最優先し、次に学習由来の分割ID別算出値またはグループ代替値を使う。<br />
グループの `inspection_threshold` はグループ単位の検査にだけ適用し、分割ID単位の代替値は学習で算出したグループ暫定閾値とする。<br />
分割ID別の上書きは対象グループに属する分割IDだけを指定でき、0以上1以下の有限な数値または `null` とする。<br />
学習済みcheckpoint、最良試行結果、型番設定の暫定閾値の整合確認は手動上書きにかかわらず維持する。<br />
異常スコアが使用閾値と等しい場合は `anomaly` とする。

#### Scenario: REQ-018-S01 検査用閾値が未指定なら暫定閾値を使用する

- **GIVEN** グループ単位の暫定閾値と整合する学習成果物があり、検査用閾値を指定していない
- **WHEN** 運用者が `test --model <型番>` を実行する
- **THEN** システムは従来と同じグループ暫定閾値で全分割を判定し、結果に使用値を記録する

#### Scenario: REQ-018-S02 明示的な null なら暫定閾値を使用する

- **GIVEN** 有効な暫定閾値があり、グループ検査用閾値が `null` である
- **WHEN** 運用者がグループ単位の検査を実行する
- **THEN** システムはグループ暫定閾値で判定し、結果に使用値を記録する

#### Scenario: REQ-018-S03 指定した検査用閾値を使用する

- **GIVEN** 暫定閾値と異なる0以上1以下のグループ検査用閾値がある
- **WHEN** 運用者がグループ単位の検査を実行する
- **THEN** システムは指定した閾値で全分割を判定し、結果に使用値を記録する
- **AND** 型番設定と学習成果物に保存した暫定閾値を変更しない

#### Scenario: REQ-018-S04 境界値を使用する

- **GIVEN** 有効な検査用閾値が0または1である
- **WHEN** 運用者が検査を実行する
- **THEN** システムはその値を対象分割の判定に使用し、スコアが使用閾値に等しければ `anomaly` と記録する

#### Scenario: REQ-018-S05 不正な検査用閾値を拒否する

- **GIVEN** グループまたは分割ID別の検査用閾値が0未満、1超、非有限、数値以外、真偽値、または未知の分割IDである
- **WHEN** 運用者が検査を実行する
- **THEN** システムは設定項目と理由を示して推論前に拒否し、既存結果を保持する

#### Scenario: REQ-018-S06 暫定閾値の不整合を上書き値で隠さない

- **GIVEN** 検査用閾値が有効でも、グループ設定・checkpoint・最良試行結果の暫定閾値が一致しない
- **WHEN** 運用者が検査を実行する
- **THEN** システムは不一致を示して推論前に拒否し、成果物の確認を促す

#### Scenario: REQ-018-S07 分割ID別の手動上書きを使用する

- **GIVEN** 分割ID単位の学習成果物があり、対象分割の検査用閾値が指定されている
- **WHEN** 運用者が検査を実行する
- **THEN** 指定した分割だけが手動上書き値で判定され、他の分割は学習由来の値で判定される
- **AND** 学習由来の値は変更されない
