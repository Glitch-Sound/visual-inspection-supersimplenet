## ADDED Requirements

### Requirement: REQ-032 グループ別の擬似異常生成範囲

システムは、運用者が `group_detail["<id>"].synthetic_anomaly` に範囲を指定して学習を開始したとき、対象グループの指定値を使用し、省略した項目には推奨値を使用しなければならない(MUST)。<br />
`synthetic_anomaly` 全体も省略できる。推奨値は `noise_std` が `{"min": 0.010, "max": 0.020}`、`perlin_threshold` が `{"min": 0.2, "max": 0.4}`、`perlin_scale_exponent` が `{"min": 0, "max": 5}` とする。`noise_std` は特徴領域に加える Gaussian ノイズの標準偏差、`perlin_threshold` は擬似異常の範囲を決める閾値、`perlin_scale_exponent` はかたまりの細かさを決める `2^n` の `n` を表す。閾値が大きいほど範囲は狭く、指数が大きいほどかたまりは細かい。

#### Scenario: REQ-032-S01 グループ別の範囲を適用する

- **GIVEN** 2グループに異なる擬似異常範囲が設定されている
- **WHEN** 運用者が各グループを学習する
- **THEN** 各グループの擬似異常には自身の設定範囲が適用され、他グループの値は使用されない

#### Scenario: REQ-032-S02 省略した項目に推奨値を使用する

- **GIVEN** あるグループで `synthetic_anomaly` 全体またはその一部が省略されている
- **WHEN** 運用者がそのグループを学習する
- **THEN** 省略した項目には所定の推奨範囲が適用され、明示した項目は保持される

### Requirement: REQ-033 mask ごとに変わる擬似異常

システムは、学習中に擬似異常の mask を1枚生成するたびに、対象グループの範囲から `noise_std` と `perlin_threshold` をそれぞれ一様分布で選び、`perlin_scale_exponent` を縦と横で独立に両端を含む整数一様分布から選ばなければならない(MUST)。<br />
`min = max` の項目は固定値とし、Perlin の scale は各方向で `2^n` とする。擬似異常を作る確率は50%とし、マスクの二値化、既存の異常領域との非重複、ラベル更新、特徴領域へのノイズ適用など、それ以外の作成手順は Anomalib 2.6.2 の SuperSimpleNet の AnomalyGenerator と同じにする。乱数は既存の学習 seed が決める torch の乱数を使い、新しい seed 項目を追加しない。

#### Scenario: REQ-033-S01 mask 単位で範囲から選ぶ

- **GIVEN** 3項目に `min < max` の範囲が設定されている
- **WHEN** 運用者が対象グループを学習する
- **THEN** mask ごとに各範囲内の値が選ばれ、指数は縦横で別々の整数として選ばれる
- **AND** 同じ学習 seed と同じ条件では同じ乱数列に従う

#### Scenario: REQ-033-S02 固定値と既存の生成手順を維持する

- **GIVEN** 3項目の `min` と `max` がそれぞれ等しい
- **WHEN** 運用者が対象グループを学習する
- **THEN** 指定値が固定で使用され、擬似異常の発生確率は50%で、その他の生成手順は既存と同じである

### Requirement: REQ-034 擬似異常範囲の入力不備の拒否

システムは、擬似異常範囲が `noise_std: 0 < min <= max`、`perlin_threshold: 0 <= min <= max < 1`、`perlin_scale_exponent: 整数で 0 <= min <= max <= 5` のいずれかを満たさない場合、学習開始前に入力不備として拒否しなければならない(MUST)。数値は有限値とし、真偽値を数値として受け付けない。設定を修正した後は再実行できる。

#### Scenario: REQ-034-S01 範囲の境界と順序を検証する

- **GIVEN** いずれかの項目で範囲外、逆順、または非有限の端点が指定されている
- **WHEN** 運用者が学習を開始する
- **THEN** 入力不備の理由が示され、探索と学習成果物の更新は始まらない
- **AND** 運用者は設定を修正して再実行できる

#### Scenario: REQ-034-S02 指数の非整数と不正な型を拒否する

- **GIVEN** 指数の端点に小数、またはいずれかの端点に真偽値などの不正な型が指定されている
- **WHEN** 運用者が学習を開始する
- **THEN** 入力不備として拒否され、既存の学習成果物は更新されない

### Requirement: REQ-035 擬似異常条件の適用範囲

システムは、擬似異常範囲が指定されている場合、これを Optuna の探索条件に含めず、学習時だけ使用し、検査では擬似異常を生成してはならない(MUST)。検査結果の形式は変更しない。正常画像のスコアの99パーセンタイル値は異常検出性能の指標として扱わない。

#### Scenario: REQ-035-S01 探索条件から除外する

- **GIVEN** グループに擬似異常範囲が設定されている
- **WHEN** 運用者が学習の探索結果を確認する
- **THEN** 擬似異常範囲は探索されたパラメータとして表示されず、99パーセンタイル値は暫定探索指標として扱われる

#### Scenario: REQ-035-S02 検査結果の契約を維持する

- **GIVEN** 新しい擬似異常範囲で準備と学習をやり直している
- **WHEN** 運用者が検査を実行する
- **THEN** 検査時に擬似異常は生成されず、既存の結果形式で結果を読み戻せる

| 要件区分 | 試験層 | 試験パターン | 自動化方針・利用者が確認する結果 |
| --- | --- | --- | --- |
| 機能要件 REQ-032〜REQ-035 | unit / integration / 対象 OS の受け入れ確認 | 省略値、グループ分離、乱数範囲と固定値、入力境界と不正型、既存生成手順、探索・推論からの分離、再実行 | 全 Scenario を pytest で自動検証する。対象 OS の実画像による学習・検査と成果物読戻しは別途記録する |
