# モデル学習の差分仕様

## ADDED Requirements

### Requirement: REQ-022 学習対象グループの選択

システムは、運用者が `train --model <型番>` を実行した時に全グループを、`--group <ID>` を指定した時にそのグループだけを学習しなければならない(MUST)。

#### Scenario: REQ-022-S01 全グループを学習する

- **GIVEN** 全グループの有効な学習準備結果がある
- **WHEN** 運用者が `train --model <型番>` を実行する
- **THEN** 各グループの学習成果物が保存される

#### Scenario: REQ-022-S02 指定グループだけを学習する

- **GIVEN** 複数グループの学習準備結果と別グループの既存成果物がある
- **WHEN** 運用者が `train --model <型番> --group <ID>` を実行する
- **THEN** 指定グループだけが学習され、別グループの成果物は保持される

#### Scenario: REQ-022-S03 不明なグループを拒否する

- **GIVEN** 型番設定に存在しないグループIDが指定された
- **WHEN** 運用者が学習を実行する
- **THEN** 利用可能なグループIDと拒否理由を示して入力不備として終了する
- **AND** 既存の学習成果物を更新しない

### Requirement: REQ-024 同じ型番の同時実行の拒否

システムは、同じ型番の `check`、`train-pre`、`train`、`test-pre`、`test` のいずれかが実行中に、同じ型番の別コマンドが開始された場合、後続の実行を理由付きで拒否しなければならない(MUST)。
異なる型番のコマンドはこの制約の対象外とする。

#### Scenario: REQ-024-S01 同じ型番の後続コマンドを拒否する

- **GIVEN** ある型番のコマンドが実行中である
- **WHEN** 運用者が同じ型番の別コマンドを開始する
- **THEN** 後続コマンドは実行中の型番を示してエラー終了し、準備・学習・検査の成果物を更新しない
- **AND** 先行コマンドは処理を継続できる

#### Scenario: REQ-024-S02 異なる型番は処理できる

- **GIVEN** ある型番のコマンドが実行中である
- **WHEN** 運用者が異なる型番のコマンドを開始する
- **THEN** 後続コマンドは先行する型番の実行を理由に拒否されない

#### Scenario: REQ-024-S03 中断後の学習成果物を確認する

- **GIVEN** あるグループの学習成果物一式の更新中に処理が中断した
- **WHEN** 運用者が同じ型番の次のコマンドを開始する
- **THEN** システムはそのグループの未完了更新を復旧してから処理を続けるか、復旧できない理由を示して既存成果物を更新せずに終了する

## MODIFIED Requirements

### Requirement: REQ-004 元画像単位の学習・検証分離

システムは、型番のグループの学習を開始する時に、対象グループに属し、ブラックリスト除外後の画像を元画像単位で学習用と検証用へ分離し、同じ元画像に由来する対象グループの全分割画像を同じ集合へ割り当てなければならない(MUST)。

#### Scenario: REQ-004-S01 既定比率と seed で分離する

- **GIVEN** 複数の元画像に由来する学習用分割画像があり、学習比率80%、検証比率20%、seed 42 が設定されている
- **WHEN** 運用者が `train --model <型番>` を実行する
- **THEN** システムは元画像単位で再現可能に学習集合と検証集合を作成する
- **AND** 同じ元画像に由来する分割画像を両方の集合へ混在させない

#### Scenario: REQ-004-S02 両集合を構成できないデータを拒否する

- **GIVEN** 元画像数が不足し、指定比率で空でない学習集合と検証集合を作れない
- **WHEN** 運用者が学習を実行する
- **THEN** システムは必要な元画像数と現在数を示して学習を開始せずにエラー終了する

#### Scenario: REQ-004-S03 不正な学習manifestを拒否する

- **GIVEN** manifestの型番・グループIDが要求と異なる、元画像名・分割画像名にパス要素がある、元画像・分割画像が重複する、分割の元画像参照が不整合である、分割IDが対象グループに存在しない、分割画像名が元画像名と2桁にゼロ埋めした分割IDから決まる名前と異なる、または準備領域・manifest・参照分割画像がシンボリックリンクである
- **WHEN** 運用者が学習を実行する
- **THEN** システムは不正な項目と理由を示して学習開始前に拒否する
- **AND** リンク先を含む準備領域外のファイルを読み書きせず、不正入力を理由に既存の学習成果物を削除しない

#### Scenario: REQ-004-S04 準備時と異なる設定を拒否する

- **GIVEN** 学習準備後に分割位置、画像サイズ、位置合わせ条件、ブラックリストまたは対象グループの分割IDが変わり、manifestの準備指紋が現在の設定と一致しない
- **WHEN** 運用者が対象グループの学習を実行する
- **THEN** システムは設定と準備結果の不一致を示して探索開始前に入力不備として終了する
- **AND** 既存の学習成果物を更新せず、`train-pre` の再実行を案内する

### Requirement: REQ-005 正常画像による学習条件探索

システムは、初期段階の学習時に、学習率倍率、バッチサイズ、エポック数、特徴抽出層および前処理画像サイズを対象グループの探索範囲内で試行し、検証用画像の異常スコアの99パーセンタイル値を最小化する条件を選択しなければならない(MUST)。
探索履歴は設定から保存先を指定させず、型番・グループIDから安全に決定したグループ別探索領域 に保存しなければならない(MUST)。

学習率倍率はSuperSimpleNetのadaptor既定学習率`0.0001`とsegmentation/detection既定学習率`0.0002`の両方へ適用して比率を維持し、`0.25`〜`4.0`を対数探索しなければならない(MUST)。バッチサイズは`4`、`8`、`16`、エポック数の初期候補は`200`、特徴抽出層は`["layer2"]`、`["layer2", "layer3"]`、`["layer3"]`、前処理画像サイズは`256`、`384`、`500`から選択しなければならない(MUST)。ImageNet正規化、bilinear補間およびantialiasは固定しなければならない(MUST)。

異常スコアはSuperSimpleNetがsigmoid適用後に返す`pred_score`とし、AnomalibのPostProcessorによる正規化および適応閾値処理を適用してはならない(MUST NOT)。`pred_score`を校正済み確率として扱ってはならない(MUST NOT)。

#### Scenario: REQ-005-S01 設定された探索を完了する

- **GIVEN** 規定された探索範囲、seed 42のTPESampler、最初の5試行と40 epochまでをwarmupとして10 epoch間隔で判定するMedianPruner、合計試行回数10、および空でない学習・検証集合がある
- **WHEN** 運用者が学習を実行する
- **THEN** システムは正常完了、枝刈り、失敗を含む合計10試行について条件、状態および報告済み指標を記録する
- **AND** 正常完了した試行のうち最小の検証用`pred_score`の99パーセンタイル値を持つ試行を最良試行として記録する

#### Scenario: REQ-005-S02 探索指標を検出性能として表示しない

- **GIVEN** 正解ラベルを持つ異常画像がない初期段階の探索が完了している
- **WHEN** 運用者が探索結果を確認する
- **THEN** システムは99パーセンタイル異常スコアを暫定探索指標として表示する
- **AND** 検出精度、再現率または本番利用可否の指標として表示しない

### Requirement: REQ-006 学習時限定のデータ拡張

システムは、対象グループの設定でデータ拡張が有効な場合、設定された種類と強度のデータ拡張を学習処理中だけ適用し、検証・試験時および保存済み画像には適用してはならない(MUST)。
システムは学習データ量からデータ拡張の有効・無効を自動判定せず、対象グループの設定の`augmentation.enabled`を使用しなければならない(MUST)。

初期値は、各軸±2%のreflection補完付き平行移動を確率0.5、±3度のreflection補完付き回転を確率0.5、係数`0.9`〜`1.1`の明るさ・コントラストを各確率0.3、6500K基準±500Kの色温度を確率0.2、係数`0.9`〜`1.1`のガンマを確率0.3、標準偏差`0.0`〜`0.01`の平均0 Gaussianノイズを確率0.3、カーネルサイズ`3`または`5`かつsigma`0.1`〜`1.0`のGaussian blurは初期状態で無効とし、有効化した場合は確率0.2で適用しなければならない(MUST)。

各変換は対象グループの設定の順序で独立に適用を判定し、連続値を範囲内の一様分布から選び、変換後の画素値を`0.0`〜`1.0`へ制限し、seed 42から再現可能な乱数列を使用しなければならない(MUST)。色温度は1000K〜40000Kに制限した黒体色近似を用いて6500Kに対するRGBチャネル倍率へ変換しなければならない(MUST)。

#### Scenario: REQ-006-S01 設定されたデータ拡張を学習へ適用する

- **GIVEN** 対象グループの設定で平行移動、回転、明るさ、コントラスト、色温度、ガンマ、センサーノイズまたはぼかしの一部が有効である
- **WHEN** 運用者が学習を実行する
- **THEN** システムは設定された順序、適用確率、範囲およびseedでデータ拡張を学習入力にだけ適用する
- **AND** 元画像および学習準備済み画像を変更せず、拡張画像を永続化しない

#### Scenario: REQ-006-S02 検証時のデータ拡張を禁止する

- **GIVEN** 対象グループの設定でデータ拡張が有効である
- **WHEN** システムが探索試行を検証用画像で評価する
- **THEN** システムはデータ拡張を適用していない検証入力から異常スコアを算出する

### Requirement: REQ-007 型番別モデル・閾値・探索結果の保存

システムは、探索完了時に、対象グループの全分割 ID を検査できる型番・グループ別の学習済みパラメータ、最良試行の条件と評価値、学習済みパラメータとの対応、および学習対象画像の`pred_score`分布の99パーセンタイル値である暫定閾値を保存しなければならない(MUST)。

暫定閾値は、最良試行のモデルをevalモード、データ拡張なし、探索時と同じ決定的前処理で学習集合へ再推論して算出しなければならない(MUST)。checkpoint、最良試行結果および型番設定の対象グループには、スコア源が`supersimplenet.pred_score`でPostProcessorが無効であるスコア契約と、同一の暫定閾値を保存しなければならない(MUST)。checkpointには型番とグループID、スコア契約および暫定閾値を保存し、最良試行結果には試行番号、探索条件、目的値、checkpoint参照、スコア契約、暫定閾値、学習・検証データ集合、seedおよび主要依存関係の版を保存しなければならない(MUST)。
対象グループの`score.source`と`threshold.score_source`は一致し、`anomalib_post_processor`は`false`でなければならず、違反する設定は学習開始前に拒否しなければならない(MUST)。

#### Scenario: REQ-007-S01 最良モデルと暫定閾値を保存する

- **GIVEN** 全探索試行が完了して最良試行が決定している
- **WHEN** 学習処理が完了する
- **THEN** システムは型番・グループ別の学習済みパラメータを保存する
- **AND** checkpointへ型番とグループID、スコア契約および学習データ由来の99パーセンタイル暫定閾値を保存する
- **AND** 最良試行の条件、評価値、対応するcheckpoint、スコア契約、暫定閾値、学習・検証データ集合、seedおよび主要依存関係の版を型番・グループ別探索結果へ保存する

#### Scenario: REQ-007-S02 事前学習重みを再利用する

- **GIVEN** 指定された `wide_resnet50_2` の事前学習重みがキャッシュに存在する
- **WHEN** 運用者が学習を実行する
- **THEN** システムは保存済みの重みを利用し、同じ重みを再ダウンロードしない
- **AND** キャッシュがない場合だけ取得して以後の実行用に保持する

#### Scenario: REQ-007-S03 成果物一式の更新失敗から復旧する

- **GIVEN** 既存のcheckpoint、型番設定の閾値および最良試行結果がある
- **WHEN** 新しい成果物一式の更新中に書込み失敗またはプロセス中断が発生する
- **THEN** システムは次の学習または検査開始前までに旧成果物一式を復旧する
- **AND** 新旧のcheckpoint、閾値および最良試行結果が混在した状態を後続処理で使用しない

#### Scenario: REQ-007-S04 不整合な最良試行結果を拒否する

- **GIVEN** 最良試行結果の型番、checkpoint参照、スコア契約または閾値が要求型番・グループの設定・checkpointと一致しない、または探索条件の型が不正である
- **WHEN** 運用者が検査を実行する
- **THEN** システムは不一致項目を示してモデル生成・推論前に拒否する
- **AND** 不整合な探索条件でモデルを構成しない

#### Scenario: REQ-007-S05 複数グループの閾値を独立に保存する

- **GIVEN** 二つのグループを異なる学習条件で学習できる
- **WHEN** 運用者が両グループの学習を実行する
- **THEN** 各グループのcheckpoint、最良試行結果、設定にグループ別の暫定閾値が整合して保存される
- **AND** 一方の保存によって他方の閾値は変わらない

### Requirement: REQ-008 探索再開と明示的な再学習

システムは、通常の学習再実行では対象グループの既存探索履歴を保持して未完了試行から再開し、運用者が最初からの再学習を明示した場合だけ対象グループの旧探索結果と旧モデルを削除して再生成しなければならない(MUST)。

#### Scenario: REQ-008-S01 中断済み探索を再開する

- **GIVEN** 対象グループの探索履歴に完了済み試行と未完了の目標試行がある
- **WHEN** 運用者が通常の学習を再実行する
- **THEN** システムは完了済み試行を保持し、残りの試行から探索を再開する

#### Scenario: REQ-008-S02 明示的な再学習で派生成果物を置き換える

- **GIVEN** 対象グループの旧探索結果と旧モデルが存在する
- **WHEN** 運用者が最初からの再学習を明示して学習を実行する
- **THEN** システムは対象グループの旧探索結果と旧モデルだけを削除して再生成する
- **AND** 元画像、型番設定および事前学習重みのキャッシュは削除しない

#### Scenario: REQ-008-S03 全グループ学習の途中失敗を示す

- **GIVEN** 一つのグループの学習が完了し、後続グループの学習が失敗する
- **WHEN** 運用者が `train --model <型番>` を実行する
- **THEN** コマンドは失敗グループIDと理由を示してエラー終了する
- **AND** 完了済みグループの成果物を保持し、失敗したグループを修正して再実行できる
