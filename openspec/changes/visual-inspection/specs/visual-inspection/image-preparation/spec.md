## Purpose

運用者が型番ごとの基準画像、位置合わせ条件、分割範囲およびブラックリストを管理し、大容量の元画像から学習・検査に利用できる追跡可能な分割画像を再現可能に準備する能力を提供する。

## ADDED Requirements

### Requirement: REQ-001 型番設定と分割範囲の確認

システムは、運用者が型番を指定して分割位置確認を要求した時に、型番設定の基準画像へ全分割範囲と分割 ID を重ねた確認画像を保存しなければならない（MUST）。

座標は左上原点、右方向を x、下方向を y とするピクセル単位とし、分割範囲は左上を含み右端・下端を含まない正方形とする。

#### Scenario: REQ-001-S01 有効な設定から確認画像を生成する

- **GIVEN** 型番の基準画像、正の画像サイズ、一意な分割 ID、および画像内に収まる左上座標が設定されている
- **WHEN** 運用者が `check --model <型番>` を実行する
- **THEN** システムは基準画像上に各分割範囲の矩形と ID を描いた型番別の確認画像を保存する
- **AND** 処理結果、出力先および処理時間を運用者へ表示する

#### Scenario: REQ-001-S02 無効な分割範囲を拒否する

- **GIVEN** 分割範囲が基準画像外にはみ出す、分割 ID が重複する、または画像サイズが正でない型番設定がある
- **WHEN** 運用者が `check --model <型番>` を実行する
- **THEN** システムは対象の設定項目と理由を示して処理をエラー終了する
- **AND** 不完全な確認画像を正常結果として保存しない

### Requirement: REQ-002 学習画像の位置合わせ・分割・除外

システムは、運用者が学習準備を要求した時に、型番の各学習元画像を基準画像へ位置合わせし、ブラックリスト対象を除外して、元画像名と2桁ゼロ埋めの分割 ID で対応付く分割画像を保存しなければならない（MUST）。

#### Scenario: REQ-002-S01 学習用分割画像を生成する

- **GIVEN** 有効な型番設定と位置合わせ可能な学習元画像がある
- **WHEN** 運用者が `train-pre --model <型番>` を実行する
- **THEN** システムは位置合わせ後の各画像から設定された全分割範囲を切り出し、`<元画像名>_<2桁分割ID>.<元拡張子>` の名称で型番別学習領域へ保存する
- **AND** 元画像は変更しない

#### Scenario: REQ-002-S02 ブラックリスト対象を除外する

- **GIVEN** 学習元画像名と分割 ID の組み合わせが型番のブラックリストに指定されている
- **WHEN** 運用者が学習準備を実行する
- **THEN** システムは該当する分割画像を学習領域へ保存しない
- **AND** 除外した元画像名と分割 ID を処理結果へ記録する

#### Scenario: REQ-002-S03 位置合わせに失敗した学習画像を除外する

- **GIVEN** 学習元画像が型番設定の最低マッチ数または信頼度を満たさず、基準画像へ位置合わせできない
- **WHEN** 運用者が学習準備を実行する
- **THEN** システムは該当する元画像の全分割を学習対象から除外する
- **AND** 元画像名、失敗理由および再確認が必要であることを警告として表示する

#### Scenario: REQ-002-S04 分割範囲外をエラーにする

- **GIVEN** 位置合わせ後の学習画像に対して分割範囲が画像外にはみ出す
- **WHEN** 運用者が学習準備を実行する
- **THEN** システムは元画像名と分割 ID を示して処理をエラー終了する
- **AND** 当該実行で生成途中の分割画像を学習可能な一式として扱わない

### Requirement: REQ-003 試験画像の位置合わせと分割

システムは、運用者が試験準備を要求した時に、ブラックリストを適用せず、型番の各試験元画像を基準画像へ位置合わせして、元画像名と2桁ゼロ埋めの分割 ID で対応付く分割画像または未判定引き継ぎ情報を生成しなければならない（MUST）。

#### Scenario: REQ-003-S01 試験用分割画像を生成する

- **GIVEN** 有効な型番設定と位置合わせ可能な試験元画像がある
- **WHEN** 運用者が `test-pre --model <型番>` を実行する
- **THEN** システムは位置合わせ後の各画像から設定された全分割範囲を切り出し、`<元画像名>_<2桁分割ID>.<元拡張子>` の名称で型番別試験領域へ保存する
- **AND** 学習用ブラックリストに一致する画像であっても試験対象から除外しない

#### Scenario: REQ-003-S02 位置合わせ失敗を検査へ引き継ぐ

- **GIVEN** 試験元画像が型番設定の最低マッチ数または信頼度を満たさず、基準画像へ位置合わせできない
- **WHEN** 運用者が試験準備を実行する
- **THEN** システムは該当元画像を正常な分割画像一式として保存しない
- **AND** 元画像名、位置合わせ失敗理由および検査時に未判定として記録すべき状態を保存して警告する

#### Scenario: REQ-003-S03 試験分割範囲外をエラーにする

- **GIVEN** 位置合わせ後の試験画像に対して分割範囲が画像外にはみ出す
- **WHEN** 運用者が試験準備を実行する
- **THEN** システムは元画像名と分割 ID を示して処理をエラー終了する
- **AND** 当該元画像を正常な検査入力として扱わない

## Test Policy

| 要件区分 | 試験層 | 試験パターン | 自動化方針 |
| --- | --- | --- | --- |
| 設定・確認画像 | unit / integration | 有効設定、範囲外、ID重複、座標境界 | 矩形座標、ラベル、終了状態、出力有無を pytest で自動検証する |
| 学習準備 | unit / integration | 位置合わせ成功・失敗、ブラックリスト、範囲外、命名規則 | 固定画像フィクスチャを用いて全 Scenario を自動検証する |
| 試験準備 | unit / integration | 位置合わせ成功・失敗、ブラックリスト非適用、範囲外 | 固定画像フィクスチャを用いて全 Scenario を自動検証する |
