## ADDED Requirements

### Requirement: REQ-038 擬似異常探索のGPU実行と設定の復元

システムは、`synthetic_auroc` を選んだグループをCUDA環境で学習する時、同じseedに基づく探索を実行し、決定論に対応しない演算を理由に試行・交差検証・最終学習を中断してはならない(MUST NOT)。<br />
学習処理の完了または失敗後は、その処理が変更した決定論設定を元へ戻さなければならない(MUST)。<br />
CPUで同じ入力・設定・seed・実行環境を使って再実行した時は、探索条件、目的値、最良試行が再現されなければならない(MUST)。

#### Scenario: REQ-038-S01 CUDAで探索から最終学習を完了する

- **GIVEN** `synthetic_auroc` と有効な正常画像が設定され、CUDAが利用できる
- **WHEN** 運用者が対象グループを学習する
- **THEN** 決定論に対応しない演算を理由に中断せず、探索、設定された交差検証、最終学習の結果を得られる
- **AND** 後続の学習処理には開始前の決定論設定が引き継がれる

#### Scenario: REQ-038-S02 失敗後も決定論設定を持ち越さない

- **GIVEN** 試行中に学習が失敗する
- **WHEN** 運用者が同じプロセスで次の学習処理を実行する
- **THEN** 前の試行が変更した決定論設定に左右されず、失敗した試行の理由を確認できる
- **AND** 完成済みの成果物は保持される

#### Scenario: REQ-038-S03 CPUで探索を再現する

- **GIVEN** 同じ入力、グループ設定、seed、CPU実行環境がある
- **WHEN** 運用者が同条件で `synthetic_auroc` の探索を最初から再実行する
- **THEN** 試行条件、目的値、最良試行が一致する

## MODIFIED Requirements

### Requirement: REQ-007 型番別モデル・閾値・探索結果の保存

システムは、探索後の学習が完了した時に、対象グループの全分割IDを検査できる最終checkpoint、最良試行の条件と目的値、正常スコアの99パーセンタイル、擬似異常スコアの分布要約、AUROC、AUROC が1.0の正常完了試行数、評価条件、およびグループで選択した方式の暫定閾値を保存しなければならない(MUST)。<br />
`training_percentile` では最終checkpointを評価モード、データ拡張なし、探索時と同じ決定的前処理でブラックリスト除外後の全正常学習集合に再適用したスコアの指定パーセンタイルを使用する。<br />
`out_of_fold_percentile` では交差検証の学習対象外スコアの指定パーセンタイルとマージンを使用する。<br />
擬似異常を評価していない旧結果では擬似指標を未測定として扱い、実測値として補完してはならない(MUST NOT)。<br />
旧結果の AUROC 上限到達件数も未記録として扱い、推測で補完してはならない(MUST NOT)。<br />
`synthetic_auroc` の正常完了試行で AUROC が1.0のものが1件以上あれば、システムは運用者へ上限到達の警告を表示しなければならない(MUST)。

checkpoint、最良試行結果および型番設定の対象グループには、スコア源が`supersimplenet.pred_score`でPostProcessorが無効であるスコア契約と、同一の暫定閾値を保存しなければならない(MUST)。<br />
checkpointには型番とグループID、スコア契約および暫定閾値を保存する。<br />
最良試行結果には試行番号、探索条件、目的名・目的値、checkpoint参照、スコア契約、暫定閾値、探索時の学習・検証集合、閾値方式、最終学習集合、閾値算出に使用したモデルの識別情報、seedおよび主要依存関係の版を保存し、新方式では交差検証分割と各元画像の分割画像別スコア、パーセンタイル、マージンも保存しなければならない(MUST)。<br />
対象グループの`score.source`と`threshold.score_source`は一致し、`anomalib_post_processor`は`false`でなければならず、違反する設定は学習開始前に拒否しなければならない(MUST)。

#### Scenario: REQ-007-S01 最良モデルと暫定閾値を保存する

- **GIVEN** 全探索試行が完了して最良試行が決定し、選択した閾値方式の算出と全件学習が完了している
- **WHEN** 学習処理が完了する
- **THEN** システムは全対象正常元画像で学習した型番・グループ別checkpointを保存する
- **AND** checkpointへ型番とグループID、スコア契約および選択方式の暫定閾値を保存する
- **AND** 最良試行の条件、目的名・値、AUROC、AUROC が1.0の正常完了試行数、正常スコアの99パーセンタイル、擬似異常スコアの分布要約、評価条件、checkpoint、スコア契約、暫定閾値、探索時集合、閾値方式、最終学習集合、閾値算出モデルの識別情報、seed、依存関係の版を保存する
- **AND** 新方式では交差検証分割と元画像ごとの分割画像別スコアを保存する

#### Scenario: REQ-007-S02 事前学習重みを再利用する

- **GIVEN** 指定された `wide_resnet50_2` の事前学習重みがキャッシュに存在する
- **WHEN** 運用者が学習を実行する
- **THEN** システムは保存済みの重みを利用し、同じ重みを再ダウンロードしない
- **AND** キャッシュがない場合だけ取得して以後の実行用に保持する

#### Scenario: REQ-007-S03 成果物一式の更新失敗から復旧する

- **GIVEN** 既存のcheckpoint、型番設定の閾値および最良試行結果がある
- **WHEN** 新しい成果物一式の更新中に書込み失敗またはプロセス中断が発生する
- **THEN** システムは次の学習または検査開始前までに旧成果物一式を復旧する
- **AND** 新旧のcheckpoint、閾値および最良試行結果が混在した状態を後続処理で使用しない

#### Scenario: REQ-007-S04 不整合な最良試行結果を拒否する

- **GIVEN** 最良試行結果の型番、checkpoint参照、スコア契約または閾値が要求型番・グループの設定・checkpointと一致しない、または探索条件の型が不正である
- **WHEN** 運用者が検査を実行する
- **THEN** システムは不一致項目を示してモデル生成・推論前に拒否する
- **AND** 不整合な探索条件でモデルを構成しない

#### Scenario: REQ-007-S05 複数グループの閾値を独立に保存する

- **GIVEN** 二つのグループを異なる学習条件で学習できる
- **WHEN** 運用者が両グループの学習を実行する
- **THEN** 各グループのcheckpoint、最良試行結果、設定にグループ別の暫定閾値が整合して保存される
- **AND** 一方の保存によって他方の閾値は変わらない

#### Scenario: REQ-007-S06 AUROC 上限到達件数を報告する

- **GIVEN** `synthetic_auroc` の正常完了試行のうち AUROC が1.0の試行が複数ある
- **WHEN** 運用者が学習結果を確認する
- **THEN** 最良試行結果から上限到達試行数を読み戻せる
- **AND** 上限到達を示す警告が表示され、実異常画像の検出性能とは区別できる

#### Scenario: REQ-007-S07 上限未到達と旧結果を区別する

- **GIVEN** `synthetic_auroc` の全正常完了試行で AUROC が1.0未満、または上限到達件数を記録していない旧結果がある
- **WHEN** 運用者が結果を確認する
- **THEN** 新結果には上限到達件数0が記録され、上限到達警告は表示されない
- **AND** 旧結果の件数は未記録として扱われ、0と推測して表示されない

#### Scenario: REQ-007-S08 最終モデルの評価スコアが不正な場合

- **GIVEN** `training_percentile` が選ばれ、最終checkpointによる再推論にスコア欠落または非有限値がある
- **WHEN** 運用者が学習を実行する
- **THEN** 理由を示して閾値算出を拒否し、完成済みのcheckpoint、設定閾値、最良試行結果を保持する
- **AND** 運用者は入力または実行環境を修正して再実行できる

### Requirement: REQ-035 全正常データによる最終モデル

システムは、最良試行が決定した時に、その条件とブラックリスト除外後の全正常元画像に由来する対象グループの分割画像で最終モデルを学習し、探索・交差検証用とは区別したcheckpointとして保存しなければならない(MUST)。<br />
`training_percentile` の閾値は、保存する最終checkpointの全正常学習集合に対する評価スコアから算出しなければならない(MUST)。

#### Scenario: REQ-035-S01 新方式の最終モデルを保存する

- **GIVEN** 交差検証と閾値算出が完了している
- **WHEN** 運用者がグループの学習を完了する
- **THEN** 最終checkpointが全対象正常元画像で学習され、最良試行結果に最終学習元画像の一覧が記録される
- **AND** 検査は最終checkpointを使用する

#### Scenario: REQ-035-S02 従来閾値方式でも全件学習する

- **GIVEN** `training_percentile` が選ばれ、最良試行が決定している
- **WHEN** 運用者がグループの学習を完了する
- **THEN** 暫定閾値は最終checkpointを全正常学習集合へ評価モード・拡張なしで適用したスコアの指定パーセンタイルであり、最終checkpointは同じ集合で学習される
- **AND** 最良試行結果に従来方式、最終学習元画像、閾値算出モデルの識別情報が記録される

#### Scenario: REQ-035-S03 最終学習の失敗を示す

- **GIVEN** 完成済みの学習成果物がある
- **WHEN** 新しい最終学習またはその保存が失敗する
- **THEN** 失敗した段階と理由が示され、完成済みのcheckpoint、設定閾値、最良試行結果は一式として保持される
- **AND** 運用者は原因を修正して学習を再実行できる
