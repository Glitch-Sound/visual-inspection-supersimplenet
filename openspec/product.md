# プロダクト概要

## 目的

本リポジトリは、型番ごとの画像準備、SuperSimpleNetによる異常検出モデルの学習、外観検査をローカルCLIで行うPythonアプリケーションである。運用者は基準画像を用いて元画像を位置合わせ・分割し、正常画像中心のデータから評価用モデルと暫定閾値を生成する。評価者は分割画像と元画像の検査結果を確認し、再撮影・追加評価・本番利用検討の判断材料とする。

## 提供する機能と開発基盤

- 型番別設定に基づく分割位置確認、学習・試験画像の位置合わせと分割
- 正常画像中心のデータによる学習条件探索、評価用モデルと暫定閾値の生成・再開
- 分割画像の異常スコア・可視化と、元画像単位の正常・異常・未判定結果の保存
- Pythonのsrcレイアウト、依存関係管理、品質チェック、テスト
- OpenSpecによる変更計画、正式仕様、設計、タスク、検証の管理

## 対象外

- 初期評価の完了だけによる本番利用の承認。検出性能、誤検出、処理時間の受け入れ基準は評価後に決定する。
- 撮影装置との自動連携、結果通知、認証・認可、GUI、Web API
- 旧モデル・旧結果の恒久保管方式

## 利用方針

- 外観検査の正式な要件は `openspec/specs/visual-inspection/` 配下の3つのcapabilityに記述する。構成と責務の案内は同ディレクトリの `README.md` を参照する。
- 振る舞いを変更する場合は、実装前に `openspec/changes/` で変更計画を作成し、完了後に正式仕様へ反映する。
- 共有する用語の短い説明は README の「よく使う用語」に置き、新しい用語や意味の変更時に更新する。正式仕様の要件や change の受け入れ条件を用語集で置き換えない。
- 本書、`tech.md`、`structure.md` はプロジェクトの共通前提を示す。正式仕様と重複する要件は記載しない。
- 実際の動作と依存関係は、コード、`pyproject.toml`、ロックファイルを正とする。
